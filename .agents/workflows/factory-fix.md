# /factory-fix

$ARGUMENTS

Use `factory-fix`, `poteto-mode`, and `ponytail`.

1. Run `node "%USERPROFILE%\.gemini\factory-home\bin\factory.mjs" fix "."`.
2. Fix root causes, add regression tests, then run `factory fix "." --retry` and `factory verify "."`.
